# DraftMind 使用指南

面向教练的使用说明，2026-10-25 更新。开发、数据生成和回测见 [README](../README.md)。

## DraftMind 是什么

DraftMind 是给职业 / 青训战队教练用的英雄联盟 BP 助手：你在网页上把双方的 Ban 和 Pick 一步步录进去，它在每一步给出 Top 8 推荐，并写明理由。

- 支持普通 BP 和全局 BP（Fearless），默认硬全局，BO1 / BO3 / BO5 都能用。
- 轮到我方时给推荐 Pick / Ban；轮到对方时预测对方可能拿什么。
- 推荐结合了职业赛版本数据、双方英雄池、克制、协同和阵容缺口，每一项都能在设置里调权重。
- 纯网页、无需后端、无需登录，打开网址就能用。数据保存在你自己的浏览器里，不会上传。

目前是手动录入：它不会自动读取游戏客户端里的 BP，需要教练或助理边看边点。

## 快速开始

**直接打开网址**：https://liu-it666.github.io/draftmind/ （Chrome 或 Edge）。`main` 分支每次更新后会自动重新部署，几分钟后生效。网址是公开的，任何拿到链接的人都能打开，但每个人的英雄池只存在自己的浏览器里，互相看不到。

**在自己电脑上跑**（开发或离线时用），大约 5 分钟：

1. 安装 [Node.js](https://nodejs.org)（选 LTS 版本，20 或 22 都可以）。装好后在终端输入 `node -v` 能看到版本号即可。
2. 下载代码：`git clone https://github.com/liu-IT666/draftmind.git`，或在 GitHub 页面点 Code → Download ZIP 解压。
3. 进入目录并安装依赖：`cd draftmind`，然后 `npm install`（只需要第一次运行）。
4. 启动：`npm run dev`。
5. 用 Chrome 或 Edge 打开 http://localhost:5173 。

以后每次使用只需要第 4–5 步。如果 GitHub Pages 在国内访问慢，也可以运行 `npm run build`，把生成的 `dist/` 文件夹放到其他静态网站托管（如腾讯云 COS、Vercel）。

注意：英雄池、当前系列赛和权重设置都存在本机浏览器里。换电脑、换浏览器或清除浏览器数据后会看不到，重要的英雄池请用「导出 JSON」备份。

## 界面导览

顶部有三个页签：**BP 台**（比赛时用）、**英雄池**（赛前准备）、**设置**（调推荐权重和数据）。右上角是区服（国服 / 外服）和英雄名语言（中文名 / English）。

| 区域 | 位置 | 做什么 |
| --- | --- | --- |
| 系列赛栏 | BP 台最上方 | 选赛制 BO1/3/5、模式（硬全局 / 软全局 / 普通 BP）、我方和对手是哪支战队、当前比分 |
| 局数栏 | 系列赛栏下方 | 切换第几局、「+ 下一局」、「新系列赛」；设置我方在蓝方还是红方、哪方先手 |
| BP 面板 | 左侧 | 蓝红双方已 Ban / 已选的英雄；已选英雄下方可以改位置 |
| 步骤提示 + 英雄网格 | 中间 | 显示「第 N / 20 步 · 我方 Pick」；搜索或点击英雄录入；空 Ban、撤销按钮 |
| 推荐面板 | 右侧 | 当前这一步的 Top 8 推荐，或对方可能的选择；连续两手时还有组合推荐 |
| 系列赛英雄池 | 最下方（仅全局模式） | 每名选手还剩哪些英雄，已锁定的灰显 |

底部一行小字会写明当前使用的统计数据来源。

## 普通 BP 怎么用

先在「英雄池」准备好双方战队，再到「BP 台」边看比赛边录入。

### 赛前：准备英雄池

1. 打开「英雄池」页签。刚打开时只有两支空战队「我方」和「对手」。
2. 任选一种方式得到战队：
    - **+ 导入职业战队**：选赛区（LPL、LCK、LEC 等）再选战队，按该队 2026-06-01 以来比赛里各位置选过的英雄生成英雄池（选过 1 次 = 3 星，2 次 = 4 星，3 次以上 = 5 星）。研究对手时最省事。
    - **+ 加载示例战队**：两支虚构战队，用来先体验一下推荐效果。
    - **+ 新建战队**：手动填选手 ID，每个位置用「添加英雄」搜索添加，再给星级。
    - **导入 JSON**：导入其他教练「导出 JSON」分享过来的战队文件。
3. 星级含义：5 = 绝活，4 = 比赛可用，3 = 能玩，1–2 = 应急。默认只推荐选手英雄池里的英雄；某个选手英雄池是空的，就不限制。

### 比赛中：录入 BP

1. 打开「BP 台」，在系列赛栏选赛制，模式选「普通 BP」，再在「我方」「对手」下拉框里选战队。改赛制会清空当前系列赛，会先弹窗确认。
2. 在局数栏设置「我方在 蓝方 / 红方」和「先手 我方 / 对方」。2026 年起边和先手是分开的（First Selection），红方也可能先手。这两项只能在录入第一步之前改。
3. 看步骤提示（例如「第 1 / 20 步 · 我方 Ban」），然后用下面任一方式录入这一步：
    - 在搜索框输入名字、称号、拼音、首字母或俗称（`ms`、`盲僧`、`瞎子`、`leesin` 都能搜到盲僧），按回车录入第一个结果。
    - 在英雄网格里直接点，可以先用上单 / 打野等按钮按位置筛选。
    - 点击右侧推荐列表里的某一项。
4. 对方放弃 Ban 时点「空 Ban」；录错了点「撤销」或按 Ctrl/⌘ + Z。
5. 英雄选完后，左侧 BP 面板会自动分配位置。如果是摇摆位英雄、分错了，在该英雄下方下拉框里改位置，占着该位置的英雄会自动对调。带「?」的位置表示不是这个英雄的常规位置。
6. 20 步录完后，点「我方胜」或「对方胜」记录结果，再点「+ 下一局」。系列赛分出胜负后不会再出现「+ 下一局」。

想回看前面某一局，点「第 N 局」即可；只有最后一局可以继续录入。

## 硬全局（Fearless）怎么用

操作和普通 BP 完全一样，只是模式选「硬全局」（默认就是它），赛制选 BO3 或 BO5。每局记录胜负并开始下一局后，前面各局的 Pick 会自动锁定。

| 模式 | 哪些英雄被锁 | 适用 |
| --- | --- | --- |
| 硬全局（默认） | 本系列赛之前各局双方选过的英雄，双方都不能再选 | LPL、LCK 等赛事，决胜局也不解锁 |
| 软全局 | 只锁自己选过的，对方选过的你还能选 | 部分杯赛或训练赛 |
| 普通 BP | 不锁 | 常规比赛 |

几条规则：

- Ban 不计入锁定，只有 Pick 会被锁。
- BO1 不锁定，选了全局模式也会提示「BO1 不锁定」。
- 被锁的英雄在网格里灰显，带「锁」字；鼠标移上去会显示原因（全局 BP 已锁定 / 本局已 Ban / 本局已选）。
- 模式可以在系列赛中途切换，不会清空记录。

全局模式下 BP 台底部会出现「系列赛英雄池」：每名选手的英雄池里已经被锁的灰掉，旁边的数字是还剩几个 4 星以上英雄。第 3–5 局前先看这里，就知道哪位选手的英雄池快见底了。

推荐也会考虑全局：用掉选手少有的 4–5 星英雄会扣「稀缺成本」分（后面局数越多扣得越多），硬全局下「抢夺」对方想要的英雄有额外加成；软全局下对方已经用过的英雄不会被推荐 Ban。

## 推荐结果怎么看

右侧面板按总分从高到低列出 8 个英雄，分数只用来比较同一步里的高低，不是胜率。点击任意一项就会录入这一步。

- **标题**：轮到我方是「推荐 Pick / 推荐 Ban」；轮到对方是「对方可能 Pick / Ban」，按对方英雄池预测。
- **位置标签**：Pick 推荐会写「打野 · 选手 ID」，表示这个英雄安排给谁。
- **彩色条**：按各维度加分分段着色，颜色对应面板底部的图例。鼠标停在条上可以看到每一项的具体分数，包括扣分项。
- **理由**：每项最多 4 条，写明为什么推荐，比如克制对线对手、补上 AP 缺口、容易被对方剩余英雄针对等。
- **连续两手组合**：轮到一方连续拿两手时（如后手方第 2–3 手），列表上方多一块组合推荐，两手一起算协同和阵容缺口，点一次录入两手。
- **英雄网格高亮**：推荐前 3 名在中间网格里也会高亮。

### 各维度含义（设置页可调权重）

| 维度 | 含义 | 默认权重 |
| --- | --- | --- |
| 版本强度 | 职业赛 BP 率和胜率，按位置折算 | 4 |
| 熟练度 | 选手英雄池星级 | 1 |
| 克制 | 对线对手的对位胜率差（已做小样本修正） | 0.5 |
| 协同 | 与己方已选英雄同队时的胜率差 | 0.5 |
| 阵容完整性 | 补足 AP/AD、前排、开团 | 0.25 |
| 翻转价值 | 能打多个位置，前几手更有价值 | 0 |
| 抢夺 | 对方想要的英雄；硬全局下额外加成 | 0.5 |
| 暴露风险（扣分） | 选了以后容易被对方剩余英雄针对 | 3 |
| 稀缺成本（扣分） | 全局 BP 下用掉选手少有的强势英雄 | 0.25 |
| 前瞻（扣分） | 模拟对方下一手的最佳应对，越强扣得越多 | 0.5 |
| 针对我方 | Ban 时额外考虑对我方已选英雄的克制 | 0.5 |

Ban 推荐 = 站在对方视角算出的 Pick 分 + 对我方已选英雄的克制。权重拖动后推荐立即更新，「恢复默认」可以还原。设置页还有两个开关：「前瞻搜索」和「仅推荐英雄池内的英雄」，默认都打开。推荐列表空了，多半是英雄池太窄，可以关掉后一个。

### 可信度

用 2026 年 9–10 月职业赛（319 局，含世界赛）回测：职业队实际的 Pick 有 38.3% 落在推荐前 5 名里，只看 BP 率的基线是 28.9%；Ban 前 5 命中 45.7%，基线 40.7%。这衡量的是和职业队选择的一致程度，不等于胜率，推荐是参考，最终决定在教练。

## 数据来源与国服 / 外服

内置统计来自 [Oracle's Elixir](https://oracleselixir.com) 的职业赛数据：2026-07-15 起 3586 局，版本 16.13–16.20，覆盖 LPL、LCK、LEC、LCS、世界赛等有记录的赛区，生成于 2026-10-25。设置页「数据」一栏会显示当前用的是哪份数据。

| 数据 | 来源 | 用在哪里 |
| --- | --- | --- |
| 英雄名、头像 | Riot Data Dragon（中 / 英） | 搜索、显示 |
| BP 率、胜率、对位、协同 | Oracle's Elixir 职业赛 | 版本强度、克制、协同、暴露风险 |
| 职业战队英雄池 | Oracle's Elixir，2026-06-01 起 | 英雄池页「导入职业战队」 |
| 自家选手英雄池 | 教练手动录入 | 熟练度、稀缺成本 |

**更新数据**：新版本或新赛事后，由开发侧运行 `python3 pipeline/oracles_elixir.py stats --since <日期>`（职业战队英雄池用 `teams` 命令）重新生成。也可以在设置页「导入统计数据（JSON）」换成自己的数据，「恢复内置数据」可以换回来。

**国服 / 外服**：右上角切换。两者用的是同一份职业赛数据（其中已含 LPL），推荐结果目前不变。区别在于提示：国服没有公开数据接口，选国服时页面底部会标明「统计数据非国服路人局，仅供参考」。英雄名语言是另一个独立开关（中文名 / English），给外籍选手看时可以切英文。

Oracle's Elixir 的数据使用需要注明来源 oracleselixir.com，页面底部已经带上。

## 常见问题与当前限制

**推荐列表是空的？** 选手英雄池里的英雄都被 Ban / 选 / 锁了。去设置页关掉「仅推荐英雄池内的英雄」，或给选手补英雄。

**推荐的英雄位置不对？** 在左侧 BP 面板里用下拉框改已选英雄的位置，后续推荐会按新位置重算。

**蓝红方 / 先手按钮点不了？** 本局已经录入了步骤。撤销到第 0 步就能改。

**前面的局点不了英雄？** 只有最后一局可以录入，前面的局只能查看。

**换电脑后英雄池没了？** 数据只存在当前浏览器里。先在旧电脑上「导出 JSON」，再在新电脑上「导入 JSON」。

当前限制：

- 只能手动录入，还不能从游戏客户端自动同步（计划在桌面版做）。
- 统计数据只有职业赛，没有外服高分段路人局，国服也没有公开数据。
- 不会根据对手近期的 BP 习惯预测对方下一手，只看对方英雄池和版本强度。
- 不支持多人实时同步同一场 BP。
- 导入的职业战队英雄池来自比赛记录，比选手真实英雄池窄，建议教练再手动补充。

英雄联盟是 Riot Games 的商标，DraftMind 与 Riot Games 无关。
